# 疯格 MAD-16

> 在线预览：https://sean-daniel.github.io/mad16/

「疯格 MAD-16」是一个非临床的当代精神状态自我观察项目。

- 4 个轴、16 种疯格、28 道题
- 包含判定标准、发作现场、收益与代价、本周处方
- 纯静态页面，无需后端与登录
- 结果仅保存在浏览器本机

## 更新方式

固定使用 `main` 分支和仓库根目录发布。后续更新只需在 `outputs/` 目录执行：

```bash
git add -A
git commit -m "update"
git push
```

不要重命名仓库、切换发布分支或把 `index.html` 移出根目录，预览地址就不会改变。

## 文件

- `index.html`：页面结构
- `styles.css`：样式
- `data.js`：类型、题目、研究资料
- `app.js`：交互与计分
